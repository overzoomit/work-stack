Multi-Agent Workflow

Structured collaboration between PM, Devs, QAs, and Docs.

Work Stack turns chaotic multi-agent prompts into a predictable software delivery pipeline with isolated tmux panes, automated ticket delegation, and autonomous sentinel supervision.

PM (0:pm)

Senior Project Manager

Defines acceptance criteria, breaks down features, organizes backlog on Plane, assigns tickets to idle Devs, and acts as the sole human communication bridge via Telegram.

Dev (dev1, dev2...)

Senior Developers

Pick up Todo or Re-open tickets, work in isolated branches/panes, write unit and integration tests, and transition issues to Test upon passing local verification.

QA (qa1, qa2...)

QA Engineers

Test strictly issues in Test state with end-to-end runtime verification, browser DOM checks, and edge-case regression. Move issues to Done or bounce back to Re-open.

Doc (doc1)

Technical Documentation

Maintains project README, knowledge bases, architecture decision records (ADRs), API references, and public documentation sites perfectly aligned with releases.

Generic (agent1)

Ad-Hoc & Script Tasks

Independent workers for benchmarking, migrations, dependency updates, and scratch debugging scripts that do not interfere with active sprint tickets.

What's New in v2.18.0

More powerful tools, fewer window switches.

From autonomous PM relay and universal command palette to docked browser preview, agent fleet telemetry, and procedural cyberpunk audio.

🤖

Dogwatch PM Autonomous Relay

When a worker agent (Dev, QA, Doc) blocks on a prompt or question, Dogwatch immediately relays it to the PM terminal (0:pm) as soon as it is idle. The PM can answer autonomously or escalate to the human user via bidirectional Telegram bot.

⌨️

Omni-Command Palette

Press Ctrl+K (⌘K on macOS) to instantly navigate anywhere: project files, Git branches, squad agents, Plane tickets, and system quick actions with instant fuzzy search.

🌐

Docked Webview & Live Browser

A lightweight browser docked alongside your code: launches automatically when a dev server prints a local address (3000, 5173, 8080…), or from the Run bar Preview button. Desktop/Mobile viewports, full navigation, and 1-click PNG QA screenshots.

🔍

Smart Diff Lens

Automatic, deterministic Git diff analysis in the changes viewer: summarizes touched files, added/removed lines, introduced symbols, and affected areas, plus 1-click Conventional Commits message generation.

🛸

Mission Control Canvas

Interactive SVG node canvas of the Agent Squad, featuring animated particle flows tracking task transitions, real-time status (idle, working, blocked), and click-to-terminal focus.

📊

Fleet Analytics Dashboard

Real-time operational telemetry and KPIs: token usage, cost estimation by model, average Dev→QA→Done cycle times, first-pass QA success rate, and native SVG sparklines.

⏳

Time-Machine & Scrubber

Travel back in time through tmux scrollback history with a visual slider and fork any historical snapshot into a new terminal window.

🔊

Cyberpunk Audio & Voice Notes

Procedural synthesizer (native Web Audio API) for contextual sound cues and event notifications; Telegram voice notes sent to the bot are cached and passed to the PM with the audio path ready for transcription.

🚨

"Needs You" Attention Center

Squad panel spotlight that aggregates pending Dogwatch prompts, enabling 1-click quick answers or custom responses without searching individual windows.

🔎

In-Buffer Terminal Search

Instant search across xterm.js scrollback buffer with Ctrl+F, concurrent match highlighting, occurrence counters, and keyboard navigation.

✈

Multi-Project & Multi-PM Telegram Bridge (oz-standard)

Single Telegram bot managing all open Work Stack projects. Flexible routing with /projects, target pinning via /use <project>, @<project> mentions, reply-to thread routing, and automatic [project] prefixes.

First launch blocked by macOS?

Work Stack is signed, but not yet notarized by Apple, so Gatekeeper may block it on first launch. Open System Settings → Privacy & Security and click Open Anyway. Alternatively, from Terminal: xattr -dr com.apple.quarantine /Applications/Work.app

Dependencies

Requires webkit2gtk-4.1, pre-installed on Ubuntu 22.04 and later. The .deb and .rpm packages install git automatically.

Arch Linux

The PKGBUILD repacks the release .deb and uses system WebKitGTK:

git clone https://github.com/overzoomit/work-stack.git
cd work-stack/packaging/arch
makepkg -si

If the window stays blank (NVIDIA, Wayland), launch with WEBKIT_DISABLE_DMABUF_RENDERER=1 work.

All releases are available on GitHub Releases.

From Source

Build it yourself.

Requires Node 22+, Rust stable, and git. Linux also requires WebKitGTK development packages.

git clone https://github.com/overzoomit/work-stack.git
cd work-stack
npm install
npm run dev      # run in development
npm run build    # bundle in src-tauri/target/release/bundle/

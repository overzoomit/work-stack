# Issue tracker

Tracker: Plane, progetto `WORKSTACK`, workspace `overzoom` (`https://plane.overzoom.it`).

- Spec di un modulo: `specs/<modulo>.md`, copiata nella descrizione del suo work item con `oz-sync`.
- Ticket: voci di `tasks/sprint-<N>/todo.md`, con i campi `File`, `Verifica`, `Manuale`.
- Blocchi: l'ordine del todo. Nessuna label di triage.
- Label `ready-for-agent` di `to-spec`: da non applicare. Dopo `to-spec` e `to-tickets` scrivi i campi di oz: «Contesto per l'agente» nella spec, `File`, `Verifica`, `Manuale` nel todo.
- Pubblicazione: `oz-sync` e `oz-publish`. Mai a mano sul tracker.
